# ⚡ DÉMARRAGE RAPIDE - eProf 3.0

## 🎯 3 clics pour activer la sauvegarde automatique

### 1️⃣ Ouvrez eProf
Double-cliquez sur **index.html**

### 2️⃣ Activez le mode automatique
En haut à droite, cliquez sur **⚡ Auto OFF**

### 3️⃣ Sélectionnez le dossier
Choisissez le dossier **Donnees** → Sélectionner

✅ **C'EST TOUT !**

Le bouton devient vert : **⚡ Auto ON**

## ✨ Maintenant

Vous pouvez travailler normalement :
- ✅ Ajoutez des notes
- ✅ Créez des évaluations
- ✅ Suivez vos élèves
- ✅ Gérez votre calendrier

**Tout est automatiquement sauvegardé** dans `Donnees/sauvegarde-auto.json` !

## 🔄 Sur un autre ordinateur

1. Copiez le dossier **eProf** complet
2. Ouvrez **index.html**
3. Vos données sont déjà là !

**Simple, non ?** 😊

## ⚙️ Configuration requise

**Recommandé :**
- Windows 10/11
- Chrome ou Edge (version récente)

**Alternative :**
Si votre navigateur ne supporte pas le mode auto, utilisez les boutons :
- **💾 Sauvegarder** : Crée un fichier de sauvegarde
- **📂 Restaurer** : Charge une sauvegarde

## 💡 Conseil Pro

Placez le dossier **eProf** dans **OneDrive** pour :
- ✅ Synchronisation automatique entre ordinateurs
- ✅ Sauvegarde cloud
- ✅ Accès partout

Structure idéale :
```
OneDrive/
└── eProf/
    ├── Donnees/
    │   └── sauvegarde-auto.json  ← Synchronisé !
    ├── index.html
    └── ...
```
