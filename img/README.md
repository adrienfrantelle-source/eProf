# Images de fond pour le Tableau Blanc

Ce dossier contient les images de fond aléatoires utilisées par le tableau blanc interactif.

## Utilisation

Ajoutez vos images de fond ici (format JPG, PNG recommandé).
Nommez-les : fond1.jpg, fond2.jpg, fond3.jpg, fond4.jpg, fond5.jpg, etc.

## Recommandations

- Résolution recommandée : 1920x1080 minimum
- Format : JPG (meilleure compression) ou PNG
- Poids : < 500 Ko par image pour un chargement rapide
- Thèmes suggérés : 
  - Tableaux noirs/verts classiques
  - Fonds géométriques neutres
  - Textures papier/ardoise
  - Motifs pédagogiques discrets

## Fonctionnement

Le fichier tableau-blanc.js sélectionne aléatoirement une image de ce dossier à chaque chargement.
Si aucune image n'est trouvée, un fond dégradé bleu-violet est utilisé par défaut.
