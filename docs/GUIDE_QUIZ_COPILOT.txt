========================================
GUIDE D'UTILISATION DU GÉNÉRATEUR DE QUIZ
VERSION MANUELLE
========================================

✍️ Le générateur de quiz permet de créer facilement des quiz interactifs 
en saisissant manuellement vos questions une par une.

========================================
ÉTAPE 1 : INFORMATIONS GÉNÉRALES
========================================

Au lancement du générateur, remplissez :

1. TITRE DU QUIZ
   Exemple : "Révisions Seconde Guerre Mondiale"

2. MATIÈRE
   Exemple : Histoire, Mathématiques, SVT, etc.

3. CLASSE
   Sélectionnez dans la liste déroulante
   Exemple : 3ème A, Terminale SAPAT, etc.

4. DURÉE ESTIMÉE (en minutes)
   Exemple : 20 minutes

5. DESCRIPTION (optionnelle)
   Exemple : "Quiz de révision pour le contrôle du 15/05"

========================================
ÉTAPE 2 : CRÉATION DES QUESTIONS
========================================

TYPES DE QUESTIONS DISPONIBLES :

📊 QCM (Choix multiple)
   - De 2 à 6 réponses possibles
   - Une seule réponse correcte
   - Par défaut : 4 options proposées
   - Vous pouvez ajouter ou supprimer des options

✅ VRAI / FAUX
   - Exactement 2 options
   - Questions simples et rapides
   - Idéal pour valider des concepts

✍️ RÉPONSE COURTE (texte libre)
   - L'élève saisit sa réponse
   - Vous indiquez la réponse attendue comme référence
   - Parfait pour définitions, calculs, expressions

POUR CHAQUE QUESTION :

1. Cliquez sur "➕ Ajouter une question"
2. Saisissez le texte de la question
3. Choisissez le type (QCM / Vrai-Faux / Texte)
4. Remplissez les réponses possibles
5. Cochez la bonne réponse (pour QCM/VF)
   OU indiquez la réponse attendue (pour Texte)
6. Définissez le nombre de points
7. Répétez pour toutes vos questions

ASTUCES :
- Vous pouvez supprimer une question avec le bouton 🗑️
- Les questions sont automatiquement numérotées
- Pas de limite de nombre de questions
- Pensez à varier les types de questions

========================================
ÉTAPE 3 : PRÉVISUALISATION
========================================

Avant de sauvegarder :

1. Cliquez sur "Valider et prévisualiser"
2. Vérifiez toutes vos questions
3. Vérifiez les bonnes réponses (affichées en VERT)
4. Si besoin, retournez à l'étape 2 pour corriger

ATTENTION : Le bouton de validation ne sera actif que si :
- Le titre du quiz est rempli
- Au moins une question est créée
- Chaque question a une bonne réponse

========================================
ÉTAPE 4 : SAUVEGARDE ET PARTAGE
========================================

Une fois satisfait :

1. SAUVEGARDER
   - Cliquez sur "💾 Enregistrer le quiz"
   - Le quiz est sauvegardé dans votre navigateur
   - Accessible depuis la liste des quiz

2. PARTAGER
   - Cliquez sur "🔗 Générer un lien de partage"
   - Un QR code est créé automatiquement
   - Les élèves peuvent scanner ou utiliser le lien
   - Le quiz s'ouvre dans quiz-eleve.html

3. EXPORTER EN PDF
   - Cliquez sur "📄 Exporter en PDF"
   - Version imprimable avec toutes les questions
   - Utile pour les contrôles papier

EXEMPLES D'UTILISATION
========================================

EXEMPLE 1 - Quiz d'Histoire (QCM)
Titre : "La Révolution française"
Classe : 4ème
Durée : 15 min

Question 1 (QCM - 1 point):
"En quelle année a débuté la Révolution française ?"
- Réponses : 1789 ✓, 1792, 1799, 1804

Question 2 (QCM - 1 point):
"Quel événement marque le début de la Révolution ?"
- Réponses : Prise de la Bastille ✓, Serment du Jeu de Paume, 
             Déclaration des Droits de l'Homme, Fuite de Varennes

EXEMPLE 2 - Quiz de Mathématiques (mixte)
Titre : "Fractions et calculs"
Classe : 5ème
Durée : 20 min

Question 1 (Texte - 2 points):
"Calcule : 1/2 + 1/4 (sous forme de fraction irréductible)"
- Réponse attendue : 3/4

Question 2 (Vrai/Faux - 1 point):
"1/3 est égal à 0,33"
- Réponses : Vrai, Faux ✓

Question 3 (QCM - 1 point):
"Quelle fraction est la plus grande ?"
- Réponses : 1/2, 1/3, 2/3 ✓, 1/4

EXEMPLE 3 - Quiz de SVT (Vrai/Faux)
Titre : "La photosynthèse - Révisions rapides"
Classe : 6ème
Durée : 10 min

Question 1 (Vrai/Faux):
"La photosynthèse a lieu dans les chloroplastes"
- Vrai ✓ / Faux

Question 2 (Vrai/Faux):
"Les plantes respirent uniquement la nuit"
- Vrai / Faux ✓

Question 3 (Vrai/Faux):
"La chlorophylle est responsable de la couleur verte des feuilles"
- Vrai ✓ / Faux

========================================
GESTION DE VOS QUIZ
========================================

Dans l'interface principale (index.html > Générateur de quiz) :

📚 LISTE DES QUIZ :
- Tous vos quiz créés sont affichés
- Informations : titre, matière, classe, nombre de questions
- Date de création

👁️ VOIR :
- Affiche le quiz complet
- Montre toutes les questions et réponses
- Permet de vérifier avant partage

📋 DUPLIQUER :
- Crée une copie du quiz
- Utile pour créer des variantes
- La copie peut être modifiée indépendamment

🗑️ SUPPRIMER :
- Supprime définitivement le quiz
- Demande une confirmation
- Action irréversible

💾 SAUVEGARDER LA LISTE :
- Exporte tous vos quiz dans un fichier .js
- Pour portabilité (autre ordinateur)
- Conserve tout l'historique

📂 RESTAURER LA LISTE :
- Importe des quiz depuis un fichier .js
- Fusionne avec les quiz existants
- Permet de récupérer des sauvegardes

========================================
CONSEILS PÉDAGOGIQUES
========================================

✅ BONNES PRATIQUES :

1. Variez les types de questions
   - QCM pour les connaissances factuelles
   - Vrai/Faux pour les révisions rapides
   - Texte pour les définitions et calculs

2. Progression de difficulté
   - Commencez par des questions faciles
   - Augmentez progressivement la difficulté
   - Terminez par des questions de synthèse

3. Points équilibrés
   - Questions faciles : 1 point
   - Questions moyennes : 2-3 points
   - Questions difficiles : 4-5 points

4. Durée adaptée
   - Environ 1 minute par question simple
   - 2-3 minutes pour questions à réflexion
   - Prévoir 5 minutes de marge

5. Formulation claire
   - Questions courtes et précises
   - Éviter les double-négations
   - Une seule bonne réponse évidente

❌ À ÉVITER :

- Trop de questions (fatigue cognitive)
- Questions ambiguës
- Réponses trop similaires
- Pièges ou questions trop techniques
- Quiz trop long (> 30 min)

========================================
DÉPANNAGE
========================================

PROBLÈME : Le bouton "Valider" est grisé
SOLUTION : 
- Vérifiez que le titre est rempli
- Vérifiez qu'au moins une question existe
- Pour chaque question, vérifiez qu'une bonne réponse est cochée

PROBLÈME : Impossible de supprimer une question
SOLUTION : Cliquez bien sur le bouton 🗑️ rouge à droite de la question

PROBLÈME : Les élèves ne peuvent pas accéder au quiz
SOLUTION : 
- Vérifiez que le quiz est sauvegardé
- Vérifiez que le lien de partage est correct
- Assurez-vous que quiz-eleve.html est accessible

PROBLÈME : Le QR code ne fonctionne pas
SOLUTION : 
- Régénérez le lien de partage
- Vérifiez que l'URL complète est correcte
- Testez d'abord avec le lien avant le QR code

========================================
RACCOURCIS ET ASTUCES
========================================

⌨️ CLAVIER :

🖱️ SOURIS :
- Clic sur une question : Éditer
- Glisser-déposer : Réorganiser (à venir)

💡 ASTUCES :
- Sauvegardez régulièrement pendant la création
- Testez votre quiz avant de le partager
- Gardez une copie PDF pour les absents
- Créez des quiz courts pour maintenir l'attention
