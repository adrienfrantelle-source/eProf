# 👥 Formation de groupes aléatoires - Tableau Blanc

## 🎯 Nouvelle fonctionnalité ajoutée !

Dans l'outil **Tableau Blanc**, vous pouvez maintenant former des groupes aléatoires d'élèves en quelques clics.

## 📍 Comment accéder

1. Ouvrez le **Tableau Blanc** depuis le menu eProf
2. Cliquez sur l'outil **🎲 Tirage au sort** (dans la barre d'outils en bas)
3. Cliquez sur l'onglet **👥 Groupes aléatoires**

## ⚡ Utilisation

### Mode 1 : Nombre de groupes défini
1. Sélectionnez votre **classe**
2. Choisissez le mode **"Nombre de groupes"**
3. Indiquez combien de groupes vous voulez (ex: 3 groupes)
4. Cliquez sur **👥 Créer les groupes**

→ Les élèves seront répartis équitablement dans 3 groupes

**Exemple :** 
- Classe de 25 élèves → 3 groupes
- Résultat : 2 groupes de 9 élèves + 1 groupe de 7 élèves

### Mode 2 : Taille des groupes définie
1. Sélectionnez votre **classe**
2. Choisissez le mode **"Taille des groupes"**
3. Indiquez combien d'élèves par groupe (ex: 4 élèves)
4. Cliquez sur **👥 Créer les groupes**

→ Des groupes de 4 élèves seront créés (le dernier peut être plus petit)

**Exemple :**
- Classe de 25 élèves → groupes de 4
- Résultat : 6 groupes de 4 élèves + 1 groupe de 1 élève

## ✨ Fonctionnalités

- ✅ **Répartition aléatoire** : Les élèves sont mélangés aléatoirement
- ✅ **Animation visuelle** : Les groupes apparaissent progressivement
- ✅ **Cartes colorées** : Chaque groupe a sa propre carte
- ✅ **Compteur d'élèves** : Affiche le nombre d'élèves par groupe
- ✅ **Répartition équitable** : Les groupes sont équilibrés automatiquement

## 🎨 Interface

Chaque groupe est affiché dans une carte colorée avec :
- **En-tête bleu** : Groupe X (nombre d'élèves)
- **Liste des élèves** : Prénom et nom de chaque membre

## 🔄 Refaire les groupes

Cliquez simplement à nouveau sur **👥 Créer les groupes** pour obtenir une nouvelle répartition aléatoire !

## 💡 Cas d'usage

**Travaux de groupe**
- Mode "Nombre de groupes" → Créez 4 groupes pour 4 sujets différents

**Ateliers tournants**
- Mode "Taille des groupes" → Groupes de 3 élèves pour des ateliers

**Projets collaboratifs**
- Groupes aléatoires pour éviter les affinités et favoriser la mixité

**Activités sportives**
- Formation rapide d'équipes équilibrées

## 🎓 Conseils pédagogiques

✅ **Variez les groupes** : Relancez plusieurs fois pour trouver la meilleure combinaison
✅ **Sauvegardez** : Prenez une capture d'écran des groupes formés
✅ **Adaptez** : Modifiez manuellement si nécessaire après formation
✅ **Communiquez** : Affichez les groupes au tableau avec le vidéoprojecteur

## 📸 Affichage en classe

Le tableau blanc peut être affiché en **plein écran** (bouton 🖥️) pour une meilleure visibilité en classe.
