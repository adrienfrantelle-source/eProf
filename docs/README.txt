=====================================
  eProf - Tableau de bord enseignant
=====================================

DEMARRAGE RAPIDE :
-----------------
Double-cliquez sur "DEMARRER_EPROF.bat" pour lancer l'application.


DEMARRAGE MANUEL :
-----------------
Ouvrez "index.html" avec votre navigateur web.


FONCTIONNALITES :
----------------
✓ Calendrier interactif (événements, todos, rendez-vous)
✓ Conversion de fichiers (CSV, XLSX, DOCX, PDF)
✓ Liens rapides (EcoleDirecte, OneDrive, Teams, Chlorofil)
✓ 100% portable - Fonctionne sans internet


RACCOURCI WINDOWS (OPTIONNEL) :
-------------------------------
Pour un accès encore plus rapide :
1. Clic droit sur "DEMARRER_EPROF.bat"
2. Créer un raccourci
3. Déplacez le raccourci où vous voulez (Bureau, Barre des tâches...)
4. Vous pouvez renommer le raccourci "eProf"


COMPATIBILITE :
--------------
✓ Windows 7, 8, 10, 11
✓ Navigateurs : Chrome, Firefox, Edge
✓ Fonctionne sur n'importe quel PC (pas d'installation requise)


SUPPORT :
--------
Toutes les données sont stockées localement dans votre navigateur.
Vos événements restent sur votre PC/clé USB.
