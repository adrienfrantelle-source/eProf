# 🚀 MODE AUTOMATIQUE ACTIVÉ !

## ✅ Félicitations !

Votre système de sauvegarde automatique est maintenant actif.

## 💾 Que se passe-t-il maintenant ?

À **chaque fois** que vous :
- ✏️ Ajoutez une note
- 📝 Créez une évaluation
- 👨‍🎓 Notez une observation
- 📅 Modifiez votre calendrier
- ⚙️ Changez un paramètre

→ Le fichier `Donnees/sauvegarde-auto.json` est **automatiquement mis à jour** (3 secondes après votre action)

## 🎯 Vous n'avez RIEN à faire !

**Travaillez normalement**, c'est tout.

Plus besoin de :
- ❌ Cliquer sur "Sauvegarder"
- ❌ Penser à exporter
- ❌ Faire des manipulations

## 🔍 Vérifier que ça fonctionne

1. Ouvrez le dossier **Donnees/**
2. Trouvez le fichier **sauvegarde-auto.json**
3. Regardez la date de modification
4. Faites une modification dans eProf (ajoutez une note par exemple)
5. Attendez 3 secondes
6. Rafraîchissez le dossier (F5)
7. ✅ La date de modification a changé !

## 🔄 Sur un autre ordinateur

**Super simple :**

1. Copiez **tout le dossier eProf** (avec le sous-dossier Donnees/)
2. Sur l'autre PC, ouvrez **index.html**
3. ✅ Vos données sont déjà là (dans sauvegarde-auto.json) !

**Vous pouvez aussi :**
- Placer eProf sur **OneDrive** → synchronisation automatique
- Copier sur une **clé USB** → portable partout

## 📊 Indicateur de statut

En haut à droite de eProf :

```
⚡ Auto ON  (vert)     ← Mode automatique actif
✓ Sauvegarde auto activée
```

Si vous voyez :
```
⚡ Auto OFF (orange)   ← Mode désactivé
Sauvegarde manuelle
```
→ Cliquez sur le bouton pour réactiver

## 🛡️ Sécurité supplémentaire

**Recommandé : Sauvegarde hebdomadaire**

Même en mode automatique, faites une copie une fois par semaine :

1. Allez dans **Donnees/**
2. Copiez **sauvegarde-auto.json**
3. Collez-le dans un dossier "Sauvegardes" avec la date
   - Exemple : `sauvegarde-2026-01-09.json`

**Ou utilisez le bouton 💾 Sauvegarder** qui télécharge une copie datée.

## ❓ Questions fréquentes

**Q : Mes données sont-elles sécurisées ?**
R : Oui, elles sont sur votre ordinateur uniquement. Pas de cloud externe.

**Q : Que se passe-t-il si je change de navigateur ?**
R : Le fichier sauvegarde-auto.json contient tout. Ouvrez simplement index.html avec le nouveau navigateur.

**Q : Je peux désactiver le mode auto ?**
R : Oui, cliquez sur **⚡ Auto ON** → Confirmer la désactivation.

**Q : Puis-je voir le contenu du fichier ?**
R : Oui ! Ouvrez sauvegarde-auto.json avec Bloc-notes ou tout éditeur de texte.

**Q : Ça fonctionne hors ligne ?**
R : Absolument ! eProf fonctionne 100% hors ligne, sauvegarde comprise.
