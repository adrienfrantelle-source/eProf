# ⚡ ACTIVATION SAUVEGARDE AUTOMATIQUE - 3 ÉTAPES

## Étape 1 : Cliquez sur ⚡ Auto OFF

![Position du bouton](Localisation : en haut à droite de l'écran)

```
┌─────────────────────────────────────────────┐
│  eProf - Tableau de bord                    │
│                              Enseignant      │
│                              email@...       │
│                     [⚡ Auto OFF] [💾] [📂]  │ ← ICI
└─────────────────────────────────────────────┘
```

## Étape 2 : Sélectionnez le dossier Donnees

Quand la fenêtre s'ouvre :
1. Naviguez dans votre dossier eProf
2. Sélectionnez le dossier **Donnees**
3. Cliquez sur "Sélectionner le dossier"

```
📁 eProf/
  ├── 📁 css/
  ├── 📁 Donnees/  ← SÉLECTIONNEZ CE DOSSIER
  ├── 📁 js/
  ├── 📁 images/
  └── 📄 index.html
```

## Étape 3 : Vérifiez l'activation

Le bouton change :
- ❌ Avant : `⚡ Auto OFF` (orange)
- ✅ Après : `⚡ Auto ON` (vert)

En dessous : `✓ Sauvegarde auto activée` (vert)

---

## ✨ C'EST TOUT !

Maintenant, **travaillez normalement** :
- Chaque modification est sauvegardée automatiquement
- Un fichier `Donnees/sauvegarde-auto.json` est créé et mis à jour
- Aucune manipulation manuelle nécessaire

## 🔄 Sur un autre PC

1. Copiez le dossier eProf complet (avec Donnees/)
2. Ouvrez index.html
3. Vos données sont déjà là ! (dans sauvegarde-auto.json)

**OU** si besoin :
- Cliquez sur `📂 Restaurer`
- Sélectionnez `Donnees/sauvegarde-auto.json`
