📋 FORMAT DES FICHIERS CSV
────────────────────────────────────────────────────────────────
Chaque fichier contient la liste des élèves d'une classe.
Format : Nom,Prénom,Sexe

Exemple de contenu :
─────────────────────
Nom,Prénom,Sexe
DUPONT,Sophie,F
MARTIN,Lucas,M
BERNARD,Emma,F
PETIT,Thomas,M

IMPORTANT :
• La première ligne (en-tête) doit rester : Nom,Prénom,Sexe
• Sexe : utiliser F pour Féminin, M pour Masculin
• Pas d'espace après les virgules
• Un élève par ligne

═══════════════════════════════════════════════════════════════
📝 COMMENT REMPLIR LES LISTES
═══════════════════════════════════════════════════════════════

1. Ouvrez le trombinoscope PDF de la classe
2. Ouvrez le fichier CSV correspondant avec un éditeur de texte
   (Notepad, Notepad++, ou Excel)
3. Ajoutez une ligne par élève avec le format :
   NOM,Prénom,Sexe
4. Sauvegardez le fichier

Si vous utilisez Excel :
• Ouvrez le fichier CSV
• Remplissez les colonnes Nom, Prénom, Sexe
• Enregistrez au format CSV (séparateur virgule)

═══════════════════════════════════════════════════════════════
🔗 UTILISATION DANS LE PLAN DE CLASSE
═══════════════════════════════════════════════════════════════

Une fois les listes remplies :

1. Ouvrez l'outil "Plan de classe"
2. Cliquez sur "Import depuis liste de classe"
3. Sélectionnez la classe souhaitée
4. Les élèves apparaissent automatiquement avec les couleurs :
   • Bleu pour les filles (F)
   • Vert pour les garçons (M)
5. Glissez-déposez les élèves sur le plan
