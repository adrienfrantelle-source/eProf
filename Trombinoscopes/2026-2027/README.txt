Année scolaire 2026-2027

Les listes officielles sont gérées par l’administrateur (panneau Admin → Élèves,
import CSV). Les photos de trombinoscope viennent des PDF Pronote du même type
que « Trombinoscope tle SAPAT A/B.pdf » (photo au-dessus du nom).

Photos déjà extraites dans ce dossier :
  photos/Tle SAPAT A/   (23 élèves)
  photos/Tle SAPAT B/   (25 élèves)

Pour un nouvel import PDF (établissement) : Admin → Élèves → Importer un
trombinoscope (PDF). Aperçu obligatoire, association aux élèves déjà en liste,
stockage en ligne (bucket student-photos). Script local de réextraction :
  scripts/extract-trombi-photos.py

Les données historiques de l’année 2025-2026 restent accessibles via Archives.
